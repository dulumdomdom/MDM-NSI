# MDM НСИ

Конфигурируемая система управления нормативно-справочной информацией для промышленного предприятия:
справочники с произвольными атрибутами, фасетные классификаторы с переменной структурой шифра,
заявки с обходными листами, роли по областям, замещение, журнал действий, обмен с АСУ, 1С и Imbase.
Работает **полностью без интернета**.

**Стек:** Vue 3 · TypeScript strict · Vite 6 · Pinia · Vue Router 4 · PrimeVue 4 · Tailwind 3 ·
MSW 2 · Vitest · Playwright.

> Бэкенда пока нет: в демо-режиме все запросы обслуживает «сервер» в браузере (`src/mocks`).
> Контракт для настоящего сервера — [docs/API.md](docs/API.md).

## Быстрый старт

**На компьютере без интернета (без Node.js):** скачайте `mdm-nsi-offline-<версия>.zip` из
[Releases](../../releases), распакуйте и запустите `start-windows.cmd` (Linux — `start-linux.sh`).
Откроется `http://localhost:8080/`. Подробно — [docs/DEPLOY_OFFLINE.md](docs/DEPLOY_OFFLINE.md).

**Для разработки:**

```bash
npm ci
npm run dev          # http://localhost:5173
```

## Демо-учётки

Пароль совпадает с логином; LDAP-пользователи — кнопка «Войти через домен», пароль `ldap`.

| Логин | Роль и области | Что делает в демо |
|---|---|---|
| `admin` | Администратор (вся система) | роли и области, структура справочников и классификаторов, обходные листы, интеграции, журнал |
| `sokolov` | Руководитель службы НСИ | согласует любые строки, правит данные, видит все заявки и журнал; без администрирования |
| `petrov` | Модератор: «Номенклатура» + классификатор инструмента (технолог ОГТ) | шифрует инструмент, проверяет заявки по номенклатуре |
| `kuznetsova` | Модератор: классификатор материалов (металловед) | шифрует материалы |
| `orlov` | Модератор: ЕСКД, крепёж, ОКПД2, спецификации (бюро стандартизации) — **в отпуске** | его строки уходят заместителю |
| `zakharova` | Нормоконтролёр спецификаций + заместитель Орлова | нормоконтроль, строки Орлова «за него» |
| `belova` | Модератор: контрагенты (ОМТС) | проверяет новых поставщиков |
| `volkova` | Бухгалтер: счета-фактуры | регистрирует и проводит счета-фактуры |
| `user` | Пользователь: номенклатура, спецификации (конструктор ОГК) | пополняет и корректирует справочник через заявки |
| `nikitina` (LDAP) | Кладовщик: номенклатура без цен | видит позиции и создаёт заявки; цен нет ни в таблице, ни в выгрузке |
| `ivanov` (LDAP) | Пользователь: контрагенты, счета-фактуры (закупки) | заявка на нового поставщика |

**Демо-данные** — условный машиностроительный завод «УЗПМ»: ~50 позиций номенклатуры по реальным ГОСТ
(свёрла ГОСТ 10902-77, болты ГОСТ 7798-70, подшипники ГОСТ 8338-75, прокат ГОСТ 2590-2006 и т. п.),
единицы по ОКЕИ, поставщики с реквизитами из открытых источников (ММК, Северсталь, Сестрорецкий
инструментальный завод; НЛМК — в заявке), спецификации по ГОСТ 2.106, счета-фактуры (НДС 20 % до 2026 г.,
22 % с 2026 г.). Классификаторы: инструмент, крепёж по условным обозначениям ГОСТ, материалы, ОКПД2,
обозначения ЕСКД по ГОСТ 2.201-80. Предприятие, номера документов и сотрудники вымышлены; реквизиты
перед использованием в учёте сверяйте с ЕГРЮЛ.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с моками |
| `npm run build` | type-check + сборка в `dist/` |
| `npm run bundle:offline` | сборка + офлайн-пакет `release/mdm-nsi-offline-<версия>.zip` |
| `npm run smoke:offline -- <url>` | проверить запущенный офлайн-пакет в Chromium: вход и справочник |
| `npm run preview` | раздать `dist/` локально |
| `npm run lint` / `npm run type-check` | ESLint (без `any`) / vue-tsc |
| `npm run test:unit` | Vitest: движок шифров, RBAC, поиск, маршруты, замещение, интеграции, CSV, данные |
| `npm run test:e2e` | Playwright (Chromium внутри `node_modules`, без сети) |
| `npm run ci` | lint → type-check → unit → build — то же, что в CI и в `pre-push` |

## Структура

```
src/
  types/       контракты данных (= API и моки 1:1)
  api/         axios; endpoints.ts — единственное место с URL
  lib/         чистые функции: classifier/ (движок шифров), rbac, routing, smartSearch, integration, csv
  stores/      Pinia: auth, catalog, classifier, request, integration, notifications, ui
  composables/ логика страниц и форм
  components/  ui/, dynamic/, classifier/, catalog/, admin/, integration/, common/
  views/       страницы
  mocks/       «сервер» на MSW: данные, обработчики, обходные листы, журнал, сохранение демо
deploy/        мини-серверы для офлайн-пакета, примеры nginx / IIS
docs/          инструкции
e2e/           сценарии Playwright
```

Подробности — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
